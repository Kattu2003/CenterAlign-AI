# Meridian shared drive (sandbox)

The contents of this folder are generated by `karya sandbox reset` and are not committed:

- `finance/vendor_list.csv` — read-only copy of the vendor master (context for AP work).
- `outbox/` — the only writable area for the AI employee (see `company/connectors/shared_drive.yaml`).

The AI employee only ever sees this folder through the `files_*` tools, under the virtual root
`shared_drive/`, and only through the gateway's path checks.
