# HR-01 New employee onboarding

Purpose: get a new joiner set up correctly before their first day — one employee record, the right system access and the right equipment, all requested through Meridian People.

## Step 1 — Read the offer letter

Offer letters are in the shared drive under `hr/offers/`. Take the candidate's full name, job title, department, start date and reporting manager from the letter (extract it with the offer_letter schema).

## Step 2 — Create the employee record

In Meridian People, create the employee with the full name, job title, department and start date from the offer letter, and select the reporting manager by name. Search the directory first: never create a second record for the same person.

## Step 3 — Work email

The work email is `firstname.lastname@meridian.example`, all lowercase, using the name as written on the offer letter (for example, Priya Sharma becomes priya.sharma@meridian.example).

## Step 4 — Default system access

Request the default access for the role, as listed in it-01 (IT access policy). Each system and level is a separate request with a short business justification.

## Step 5 — Extra access

Access beyond the defaults needs a business justification from the request. Anything at admin level requires IT Admin approval (policy HR-001); the system holds the request until Vikram Desai decides. Request it separately from the default access.

## Step 6 — Equipment

Request equipment by role: analysts get a `standard_laptop`; engineers get a `developer_laptop`. Request a monitor only when the offer letter or the request asks for one.

## Step 7 — Report

Report the new employee ID, the work email, every access request (and which are waiting for approval) and the equipment requested.
