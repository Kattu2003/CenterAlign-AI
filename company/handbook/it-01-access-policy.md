# IT-01 System access policy

Purpose: give people the access their role needs, and no more.

## Default access by role

- Data Analyst: erp viewer, mail viewer.
- Engineer (software, data or hardware): github editor.
- Finance and accounts staff: erp editor, mail editor.
- HR staff: hr editor, mail viewer.

Roles not listed get no default access; ask HR.

## HR-001 — Admin access needs IT Admin approval

Any admin-level access, on any system, requires approval by the IT Admin (Vikram Desai, role `it_admin`) and a business justification. Admin access is requested separately from default access.

## Access levels

viewer = read only; editor = create and update records; admin = configuration and user management.
